KEY CONCEPTS
============

1. TYPE CONSTRAINTS
   → Enforced at definition time, not just documentation
   Example: `pageSize?: int & >=1 & <=100`

2. REUSABLE PATTERNS
   → #ErrorResponse used in 50+ endpoints, defined once
   Example: All endpoints use same error structure

3. UNION TYPES (OneOf)
   → Multiple alternatives enforced at schema level
   Example: #NotificationChannelRequest can be Email|Webhook|SMS

4. REFERENCE SCOPES
   → Templates specialize correctly through relative references
   Example: #CRUDTemplate creates generic operations
             #DocumentCRUDEndpoints fills placeholders with Document types

5. FIELD-LEVEL COMPOSITION
   → Combine templates with specific types using &
   Example: #CRUDTemplate.Create & { request: #DocumentResource }
